# Keidai — Japanese Temple & Shrine Website Template

A visually rich Japanese temple website with illustrated 
hero, animated lanterns, sakura petals, and deep crimson 
editorial design. Built with Next.js and Tailwind CSS.

## Tech Stack
- Next.js 14
- Tailwind CSS
- TypeScript
- GSAP / CSS Animations

## Getting Started

1. Extract the zip file
2. Install dependencies:
   npm install
3. Run the development server:
   npm run dev
4. Open http://localhost:3000 in your browser

## Customization
- Replace hero illustration in `/public`
- Update temple info in `/app` and `/components`
- Edit colors in `tailwind.config.ts`
